## 1.1.0

- Lives where it belongs: Minecraft → Network & Bedrock and the “Connect” card of every server – no own sidebar entry any more (Hostwerk 3.0+); the full page stays under Extensions → Open and can be pinned in the sidebar settings. / Steckt jetzt dort, wo sie hingehört: Minecraft → Netzwerk & Bedrock und Karte „Verbinden“ jedes Servers – kein eigener Seitenleisten-Eintrag mehr (Hostwerk 3.0+); die ganze Seite bleibt unter Erweiterungen → Öffnen und lässt sich in den Seitenleisten-Einstellungen anheften.

## 1.0.0

- First version: one place for everything around several Minecraft servers and platforms. Replaces “Bedrock bridge” and the Minecraft part of “Game server network”. / Erste Fassung: ein Ort für alles rund um mehrere Minecraft-Server und Plattformen. Löst „Bedrock-Brücke“ und den Minecraft-Teil von „Spiele-Server-Verbund“ ab.
- Networks with Velocity (modern forwarding, through Hostwerk’s core) or BungeeCord (new server type through SDK 3.2): lobby, order, forced hosts, maintenance per server, MOTD, icon, player count, ping passthrough, start/stop in order, checks, addresses. / Netzwerke mit Velocity (modern forwarding, über Hostwerks Kern) oder BungeeCord (neuer Servertyp über SDK 3.2): Lobby, Reihenfolge, forced hosts, Wartung je Server, MOTD, Symbol, Spielerzahl, Ping durchreichen, Starten/Stoppen der Reihe nach, Prüfung, Adressen.
- Shared whitelist, operators and bans for the whole network (Java through Mojang, Bedrock through the Floodgate prefix); moving players between servers. / Gemeinsame Whitelist, Operatoren und Sperren für das ganze Netzwerk (Java über Mojang, Bedrock über den Floodgate-Vorsatz); Spieler zwischen Servern verschieben.
- Bedrock: Geyser + Floodgate once on the proxy (one key for every server, created by Hostwerk before the first start), on a single server, or Mojang’s Bedrock Dedicated Server. Geyser’s new config layout (2.9+) is understood. / Bedrock: Geyser + Floodgate einmal am Proxy (ein Schlüssel für alle Server, von Hostwerk vor dem ersten Start angelegt), auf einem einzelnen Server oder Mojangs Bedrock Dedicated Server. Geysers neues Konfigurationsformat (2.9+) wird verstanden.
- Version bridges ViaVersion/ViaBackwards/ViaRewind on every server behind the proxy. / Versions-Brücken ViaVersion/ViaBackwards/ViaRewind auf jedem Server hinter dem Proxy.
- Without maintenance: Geyser/Floodgate, proxy builds and Bedrock Dedicated Server update themselves when nobody is online – with checksums, compatibility check, probe and a way back. / Ohne Wartung: Geyser/Floodgate, Proxy-Builds und Bedrock Dedicated Server aktualisieren sich, wenn niemand online ist – mit Prüfsumme, Verträglichkeitsprüfung, Probe und Rückweg.
- Moving over from the Bedrock bridge without loss: same data, same port, same Floodgate key; Geyser behind a proxy moves onto the proxy with one click. / Umzug aus der Bedrock-Brücke ohne Verlust: gleiche Daten, gleicher Port, gleicher Floodgate-Schlüssel; Geyser hinter einem Proxy zieht mit einem Klick auf den Proxy.
